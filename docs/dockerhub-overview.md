# Trello MCP

A self-hostable Model Context Protocol server for Trello boards, lists, cards, checklists and more. Connect an MCP client over stdio or Streamable HTTP. This independent, community-maintained project is unaffiliated with Trello and Atlassian. [Source repository](https://github.com/enthouan/trello-mcp) · [Setup and client guides](https://trello-mcp.com/getting-started/clients/)

Choose an exact `X.Y.Z` tag for a stable release on linux/amd64 or linux/arm64. Docker Hub's `latest` follows the newest eligible stable release. The primary registry, `ghcr.io/enthouan/trello-mcp`, also offers a `latest` tag that follows main. [GHCR package](https://github.com/enthouan/trello-mcp/pkgs/container/trello-mcp)

The mirror preserves the GHCR index digest and both platform images with their original SPDX SBOMs and BuildKit provenance. [Supported tags and verification](https://github.com/enthouan/trello-mcp/blob/main/docs/dockerhub.md)
