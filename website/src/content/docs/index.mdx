## Let your MCP client create a Trello card for you

This example creates one real card in an existing list in your connected Trello account. Your MCP client can discover the board and list IDs, so you only need to choose the destination and supply a card title.

```text title="Card creation example prompt"
Create a Trello card for me.
Ask which board, list, and title to use.
Show the proposed card_create call and wait for my approval.
```

<Steps>
1. **Choose the destination.** The client uses the read-only `list_boards` and `board_lists` tools so you can choose an existing list without finding IDs yourself.

2. **Review the proposed call.** Confirm that `card_create` has the intended `listId` and card `name`. It creates one persistent card.

3. **Create the card.** Approve the write. If it was only a test, use `card_archive` instead of permanently deleting it.
</Steps>

<Aside type="caution" title="Before approving a write">
  Use `auth_whoami` to confirm the connected Trello account. Discovery tools are read-only, but write tools make persistent changes in Trello. Confirm the target and intended change, and use a disposable board for trial mutations.
</Aside>

## Useful by design

Use natural-language requests in an MCP client to search, inspect, and maintain the Trello resources your configured token can access.

<CardGrid>
  <Card title="Find and summarize work" icon="magnifier">

    `search → card_get → card_actions`
  </Card>

  <Card title="Create and organize cards" icon="add-document">
    Discover the board and its lists, create a card in the intended destination, then move it when the workflow changes.

    `list_boards → board_lists → card_create → card_move`

  <Card title="Coordinate with collaborators" icon="comment">

## Know when to use it

Choose this community server when self-hosting, local stdio, an inspectable deployment, or broad Trello REST automation matters. Choose Trello's official MCP service when you prefer a Trello-hosted connection, OAuth consent, official support, and a workspace-scoped managed service.

See the [full side-by-side comparison](/guides/faq/#which-trello-mcp-server-should-i-choose), last checked **August 10, 2026** against Trello's official MCP documentation.

Naturally, the [public `trello-mcp` roadmap](https://trello.com/b/GnKmvuHz/trello-mcp-enthouan-trello-mcp) is itself a Trello board. Follow it to see what is planned, active, and shipped.
